# Обновление сообщений отчёта о поиске

Кнопка «📄 Подробности» публикует только **один** отчёт для каждого поискового задания. Повторные нажатия редактируют это сообщение через `edit_message_text`; уже открытый отчёт обновляется автоматически по мере поиска. ID сообщения сохраняется в БД, чтобы редактирование работало после перезапуска.

Миграция `20261029_0020` автоматически выполняется при старте ConfPlanner через `run_migrations`.

Изменены:
- `src/conference_planner/bot/discovery_progress.py`
- `src/conference_planner/db/models.py`
- `migrations/versions/20261029_0020_discovery_report_message.py`
